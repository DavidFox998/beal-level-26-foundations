# `GaloisRep/`

Vendor “Real” Galois-representation modules for the Frey curve
at level 26. File names ending in `Real` record interfaces
(determinant cyclotomic, finite-flat at 13, unramified /
semistable, modular lifting, Ribet modularity) used by the
historical Track A narrative.

These modules do **not** inhabit Mazur irreducibility of
`ρ_{E,13}` or abstract Ribet level-lowering. Those remain
`def Prop` on the v26 slice:
