# v4.0.1-jacobian-skeleton — finite J₀(26) product and Picard Prop

This release adds the missing Jacobian *skeleton*. It does not construct
a Mathlib Jacobian.

`BealLevel26Foundations.Jacobian.J0_26_DecompActual` loads the v1.4.0
sources via the already-promoted Lean ledger:

* `sagemath/level_26_ledger.json` SHA-256
  `0259fe957cc348b7286e233ce717fac47c30ad174b05e8e1c5fb70626f511151`;
* `sagemath/certs/j0_26_decomposition.json`;
* `sagemath/certs/formal_immersion_M3.json`.

It defines the finite model `s₁ = q₁ + q₂`, `s₂ = -q₁ q₂` and proves the
certified product `J₀(26) = 26a × 26b` as the `a₂ = -1` versus `a₂ = 1`
distinction, together with `M₃ = [[1, 1], [0, 2]]` and `det = 2` by
`decide`.

`BealLevel26Foundations.Jacobian.PicardAbelJacobiIdentification_26`
is the standalone `Prop` that a supplied matrix equals the q-expansion
`M₃`. That declaration was moved out of
`QExpansionCotangent_Real_26.lean`.

No new certificate is added. The v1.4.0 ledger is unchanged. This is not
a scheme-theoretic Jacobian, Mordell--Weil, or Abel--Jacobi theorem.

The version DOI is minted by tagging `v4.0.1-jacobian-skeleton` on the
public GitHub archive. This note does not invent a DOI number.
