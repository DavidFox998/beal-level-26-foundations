# v4.0.0-mazur — Mazur endgame scaffold

This release starts the PLAN.md v4.0.0 Mazur milestone. There is no v2.1.

`BealLevel26Foundations.Mazur.EndgameScaffold` carries four typed premises:

1. `J0_26_Q_RankZero26` — rank-zero boundary. No Mathlib Jacobian.
2. `FormalImmersionAtTwo26` — carries the v1.4 certificate
   `M₃ = [[1, 1], [0, 2]]`, `det = 2`, and proves only that immersion
   *input*. It does not prove actual formal immersion.
3. `X0_26_RationalPoints26` — displayed four cusps, premise-bearing.
4. `NoFreyPoint26` — `X₀(26)(ℚ) = 4` cusps implies no level-26 Frey point.

`BealTheoremFromMazurChain26` concludes `BealTheorem` only from those
four structures together with v3 `LevelLowering_26` and the v2 Frey
Weierstrass model.

Mathlib 4.12 has no Jacobian, Mordell--Weil group, or formal-immersion
API. Rank, actual immersion, the four-cusp identification, and `R = T`
are not discharged by `decide`.

This is not an unconditional `BealTheorem`.
