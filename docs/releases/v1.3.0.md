# v1.3.0 — J₀(26) decomposition and M₃ certificates

This release records SageMath 10.7 output for:

- the abelian-variety decomposition `J₀(26) ≅ 26a × 26b`, dimension 2;
- the Cremona models `26a1 = [1,0,1,-5,-8]` and `26b1 = [1,-1,1,-3,3]`;
- the modular-symbols new-cuspidal dimension 2;
- the derived matrix `M₃ = [[1,1],[0,2]]` over `𝐅₃`, of rank 2.

The JSON archives are `sagemath/certs/j0_26_decomposition.json` and
`sagemath/certs/formal_immersion_M3.json`. Lean 4.12 promotes those numbers
in `Beal.Foundations` and proves only Weierstrass algebra and agreement with
the existing coefficient ledger. It does **not** construct a Mathlib Jacobian,
prove Mordell--Weil rank, or identify `M₃` with a geometric Picard/Abel--Jacobi
cotangent map.

There are no `sorry`, `admit`, vacuous `True` declarations, or domain-specific
axioms in the Lean source.

connected to Zenodo. This note does not invent a DOI number.
