# v2.0.0-frey — Frey Weierstrass model and odd-prime valuation input

This release starts the PLAN.md v2.0.0 Frey discriminant milestone.

`BealLevel26Foundations.Real.FreyWeierstrass` defines the integral Frey
model from `beal-conjecture`:

`Y² = X (X - Aˣ) (X + Bʸ)`,

with `a₁=a₃=a₆=0`, `a₂ = Bʸ - Aˣ`, `a₄ = -(Aˣ Bʸ)`. It proves `c₄`, `c₆`,
and `Δ` by `ring`, including the Beal-equation form
`Δ = 16 (Aˣ)² (Bʸ)² (Cᶻ)²`.

`Conductor_26_Unconditional` proves the odd-prime valuation input
`vₚ(c₄)=0` and `vₚ(Δ)>0` from `p ∤ c₄`, `p ∣ Δ`, and `Δ ≠ 0`. It does not
import `frey_conductor_data` or `tate_step2_odd_prime_external`.

`TateKodairaBoundary26` records that the Tate/Kodaira classification
(type `Iₙ`, local conductor exponent one, `N = 2^e * rad(ABC)`) is an
explicit boundary. It is not discharged by `decide`.

This is not a replacement of the parent `FreyCurveExists` supplier, not a
Kodaira theorem, and not an unconditional Beal theorem.
